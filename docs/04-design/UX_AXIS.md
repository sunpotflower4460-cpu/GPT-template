# UX_AXIS.md

## 禁止（既定値の見た目）

- 中央寄せヒーロー + グラデーション背景
- 未調整のデフォルト青のプライマリボタン
- 絵文字によるアイコン代用
- 影付きカードの多用、全要素一律の角丸
- "Get Started" 風の汎用CTAコピー
- 生成AIに頻出する3パターン（いずれも「選択」ではなく「既定」なので、ブリーフが明示的に指定しない限り採用しない）:
  1. クリーム地（#F4F1EA 近辺）+ 高コントラストのセリフ見出し + テラコッタ系アクセント
  2. ほぼ黒の地 + 単色のアシッドグリーン/朱のアクセント
  3. ヘアラインの罫 + 角丸ゼロ + 新聞的多段組

## 必須

- 色・サイズは `tokens.css` の変数のみを使用
- 余白は4 / 8pxグリッド
- タイポグラフィは6段階のスケールのみ
- アニメーションは1画面2箇所まで、各200ms以内
- 1画面の第一階層要素は最大5つ

## 原則（1行）

> 余白と階層で語る。装飾で語らない。

## 追加前の手順

> UI要素を1つ足す前に、減らせる要素を1つ挙げること。挙げられないなら足さない。
